# 自私的基因

开源Jev的强化学习生存训练。

基于 Rulebook v0.5，并按当前 v0.7 数值修订实现的可编辑像素沙盘。默认使用四组优先策略，遇到问题或冲突时回退到所属队伍的 Jev 服务；四队默认共用当前 Jev-0.8B，也可分别连接自己的服务，未做沙盘微调。

默认 **24×24**，四族各 **5** 人起始（总计20人），总存活人口上限 **100**、单族上限 **50**。地图尺寸、初始人数及两项上限都可在参数面板查看和修改。

当前默认 `decisionMode=hybrid`：A混沌战帮（纯个人生存）、B阿美瑞卡（自利为主）、C神圣泰拉（群体为主）、D蜂巢意志（无自私基因，全种群生存）；各组分别规定补给、繁殖、援助与探索优先级。连续失败、补给与交战冲突、矛盾消息等情况才调用Kev。国王国家倾向和技能升级也优先使用规则，页面和日志标明来源；可切回 `kev` 模式。

当前个人初始 **10 E**，每族初始公账 **30 E**。占领一个地块从本族未预留公账扣 **5 E**，公账不足则失败。每次成功占地额外生成 **1 E** 给占领者，个人容量溢出入公账；每块已有领土每回合另生成 **0.1 E地税** 进入公账，再发生活费。出生领地也计税，新占格从下一回合起计税，矿点占领奖励另行叠加。扩张优先四邻接边界、填补缺口、连接已有地块，仍允许远处矿点作为战略目标。移动每次上下左右累计最多 **3步**、可拐弯、不能穿过个体或阻挡建筑，成功费仍为每次1 E；攻击当前可见、横纵距离之和不超过 **3格** 的目标，攻击费仍为4 E、基础伤害10 E。

击杀敌方获得其致命伤害结算前全部剩余个人能量，不夺取敌族公账。多人合击归伤害最高者，同伤害按固定种子裁定；溢出或获益者同时死亡时入本族公账。地图按真实结算路径播放移动和转弯动画，按实际战斗坐标播放弹道、命中和击杀动画，死亡或移动后的目标仍在受击位置显示效果。

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

打开 http://127.0.0.1:8765 。需要 Node.js 22+。也可直接用 `node server.mjs` 启动；运行时无 npm 依赖。`npm.cmd install` 仅用于安装浏览器测试工具。

跨平台启动：

```sh
git clone https://github.com/yw2598/Selfish_Jev.git
cd Selfish_Jev
npm start
```

## 连接你的 Jev 与 LLM

顶部「服务端点」提供四队独立 Jev 设置和一个共享 LLM 设置。四队分别为 A 混沌战帮、B 阿美瑞卡、C 神圣泰拉、D 蜂巢意志；普通行动、国王国家倾向和技能升级都路由至所属队伍的服务。

| 服务 | 当前默认端点 | 当前默认模型 |
| --- | --- | --- |
| A / B / C / D Jev | `http://127.0.0.1:8108` | `kev-latest` |
| 共享 LLM | `https://openrouter.ai/api/v1` | `qwen/qwen3.8-flash` |

四队可填写相同地址，也可分别使用四个服务。Jev 填服务基础地址，不带 `/v1/systemone`；LLM 填 OpenAI 兼容 API 基础地址，不带 `/chat/completions`，LLM 留空时使用模板回退。端点从 Node 服务端访问，本机当前部署继续使用现有服务；**在其他机器克隆后，需要填写该机器能访问的 Jev 地址及自己的 LLM 密钥**，仓库不提供原部署的 SSH 权限或账号额度。只查看内置演示无需模型服务。

每项可填 API 密钥。留空保留已保存密钥，勾选清除则删除该端点的凭据。服务设置在暂停后保存，下回合生效；各队连接状态和 LLM 测试独立显示。配置随沙盘检查点恢复，密钥单独保存在服务端 `artifacts/service-secrets.local.json`，不回显、不进入报告/回放，也不提交到 Git。也可复制 `.env.example` 为 `.env.local` 设置服务端默认语言密钥。

Jev 协议与可选 SSH 配置见 [连接服务](kev-deploy/CONNECTING.md)。四队使用相同服务配置时共享并发池（默认 8），不同配置独立排队；LLM 默认 4 并发。当前决策方式为 `hybrid`，若希望所有决策都交给模型，可在参数配置改为 `kev`。

## 沙盘规则

地图自动生成草地、森林、沙地、水面和山地，全部地块均可通行，地形只影响外观。默认24×24、种子20260927生成 **4座初始矿＋8座中立矿，共12座**。`resourceCount=12` 指定矿点总数；设为null时才按 `resourceDensity=0.5` 自动生成。当前不保证每个5×5视野内都有矿。

默认每族出生领地内有一个矿点，每回合产出10 E、库存上限100 E、初始库存50 E；四矿计入资源总数。占领矿的库存与每回合产出自动进入本族公账，不再执行HARVEST。随后公账向每个存活族人（含国王）自动发放 **1 E生活费**，无需授权/领取动作；资金不足时按实际余额与收入均分，余款由国王管理。首次占领中立矿奖励 **10 E**，每矿一次；每次从敌族夺取矿点另奖励 **10 E**。奖励优先进入占领者个人账户，容量溢出入公账；初始自带矿无个人奖励，本族已有矿点不能重复占领奖励。

当前本机默认通过 `http://127.0.0.1:8108` 连接已有的 Jev-0.8B 服务。可选 SSH 隧道只在本地配置了目标时启用，不会部署或重启远端模型。

繁殖改为单个个体独立执行：投入10/20 E给同族子代，另付5 E手续费，无需配对；子代下一回合行动。所有目标共用失败条件：本族最后一个个体死亡即本族失败，自私模式同样需要判断种群延续风险。

默认语言服务为 OpenRouter 的 `qwen/qwen3.8-flash`，负责通信正文和**族群共享记忆压缩**；规则负责常规行动，Kev只处理回退决策；规则补给广播使用固定正文，规则决策不调用语言压缩。密钥通过本机服务端 `.env.local` 的 `LANGUAGE_API_KEY` 加载，并用 `LANGUAGE_API_KEY_ORIGIN=https://openrouter.ai` 限定发送目标。该文件已忽略，不进入网页、配置导出或实验存档。

Kev 默认8并发，语言服务独立4并发，页面显示实际活跃请求数；可在参数面板调整。个人观察、私人回执和私人记忆不发给语言压缩器，按容量展示原始记录；只有已投递的同族共享消息进入压缩，相同来源复用结果，新生个体不会获得自己未收到的历史。

国王每回合额外选择一次国家倾向，免费且不占普通行动，当回合全族生效：**激进**主动对敌作战；**保守**倾向远离敌方单位；**中立**守卫己方矿区、不主动进攻敌方矿点。三种倾向都会主动探索并占领无主矿。敌方可以占领矿点，下一回合矿产转给新主人，首占奖励不重复。

四种模式均加入温和探索倾向：有生存余量时接近并占领已知中立矿、探索未知区域；仍保留各自权重和本族灭绝失败条件。`explorationTendency` 可设 `none` / `moderate` / `strong`，只改变提示词，不强制动作或改写Kev概率。

## 回放演示与视频剪辑

「回放演示」Tab 包含「回放剪辑」和「成片演示」两个子页。首次进入默认载入内置100回合演示，也可选择本机历史实验载入。可逐回合拖动、调速、按重大事件跳转；剪辑列表支持指定起止回合、追加、删除、上移及一键高光，浏览时间轴不会覆盖剪辑列表。

高光剪辑保留开场与最终回合，优先选取灭绝、夺矿和首次交战等事件。画面内同时显示阵营标识、人口、矿点、领土、公账与事件字幕；合成音效可关闭。导出1280×720 WebM视频，含音轨及有限时长元数据，可在成片页播放或下载。导出时保持页面可见，切页/隐藏会取消录制并保留剪辑。

仓库自带 [完整前100回合720p成片](demo/selfish-gene-demo.webm)、[100回合回放数据](demo/demo-replay.json) 和 [完整逐回合战报](demo/first-100-turns.md)，保存在 `demo/`，新模拟不会覆盖。进入「成片演示」默认加载该视频，点击播放即可。视频从T0到T100连续展示，约102秒，逐回合不跳剪；基于已校验的v0.6版本记录，共291条详细事件。新规则的回放按日志中实际配置显示，不将新经济规则套用到旧轨迹。原本机 `artifacts/` 中若已有示例文件，优先使用它们。

事件可按类型、涉及队伍、个体编号或坐标检索。点击事件后，下方「本回合详情」展示参与者、坐标、伤亡原因、矿权变化、已结算的援助和公账变化；经济卡片区分矿产收入、回合末公账、生活费实发与应发。旁栏可下载当前回放的完整 Markdown 战报，逐轮覆盖1～100回合。高光剪辑仍可手动生成，但不会替代默认的全程演示。

回放在独立Worker中重建，不调用Kev/语言模型，也不会推进当前沙盘。地图编辑、调参、故障回退均按日志恢复；每回合与记录中的人口/经济统计核对，不一致时明确停止。运行中的日志仅读取生成任务开始时的完整记录，载入后再次点击可刷新到最新回合。

验证：`node --test tests/replay.test.mjs`；`node scripts/replay-browser-check.mjs`（会重新制作示例成片）。

服务验证：`node --test tests/services.test.mjs`；`node scripts/services-browser-check.mjs`。浏览器检查需先 `npm ci`，默认使用已安装的桌面 Edge；服务检查也支持通过 `BROWSER_CHANNEL` 指定 Playwright 浏览器通道。
