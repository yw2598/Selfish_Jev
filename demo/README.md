# 固定的 100 回合演示

- `demo-replay.json`：由真实历史日志校验重建的 101 帧（T0～T100），291 条详细事件。
- `selfish-gene-demo.webm`：完整前100回合，T0～T100逐回合连续播放，1280×720，约102秒，含原创合成音效和事件字幕。
- `replay-demo.json`：成片元数据。
- [完整逐回合战报](first-100-turns.md)：100回合的指标、各族矿产收入、公账变化、生活费、倾向及详细事件。

这是 v0.6 规则下的历史实验，画面保留当时规则；新建实验使用当前 v0.7。回放数据不包含 API 密钥、SSH 配置、私人提示词或原始完整日志。

首次进入「回放演示」默认载入这份 100 回合回放；切到「成片演示」默认载入示例视频。新实验不会覆盖本目录。

事件包含矿权转移、逐轮交战、繁殖、伤亡、国家倾向变化、国王更替、实际个体援助、生活费不足与灭绝。网页可按类型、队伍、个体编号或坐标搜索，点击事件查看对应回合的完整详情，也可下载战报。

统计边界：100回合共86人出生、43人死亡，71次成功跨族攻击；27次实际个体转账中有10次跨族转账，不据此认定稳定联盟。神圣泰拉T72灭绝时公账2458.99 E，T100余额2678.99 E；灭绝后尚未被夺走的矿点仍入账，不能混淆两个时间点。T100最终人口为A50、B0、C0、D13。
